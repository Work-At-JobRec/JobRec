# JobRec

The applicant-focused job board you didn't know you needed

# Accessing JobRec

JobRec is currently live at jobrec.thecoolsite.org, and it is automatically synced with the main branch of this repository.

Be aware that logging into the hosted JobRec instance will involve giving the JobRec team your email address, and if you use github/google SSO, we may get info about your accounts there as well.

If you want to try your hand at self-hosting this app, you will need to first get an openai API key and an auth0 application with an API audience. Then, you can use vite and python to run the frontend and backend. Refer to the .env.example file and aws deployment script to learn more. Since self-hosting isn't the goal of this application, we won't be providing any local installation scripts or further assistance.

## First Steps for Reviewers
1. Navigate to jobrec.thecoolsite.org
2. Log in or create an account
3. Upload your resume and start using the site
