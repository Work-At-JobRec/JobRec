## Purpose

Check, end to end against real sources, that what JobRec stores for a listing is what the company actually posted: title, link, description, location and status.

## Procedure

1. Controlled test sources, one per scraper type: Figma (Greenhouse), Palantir (Lever), Ramp (Ashby).
2. Scrape them into a new, empty database with the same entry point the scheduled scrape uses (`scrape_sources`). Skill detection was disabled with a placeholder OpenAI key, so its errors appear on stderr and nothing else is affected.
3. Fetch the same three boards again directly from their public APIs, without going through JobRec's scrapers.
4. Draw 25 stored listings at random (seed 27) and compare each with its live record:
   - title and location, whitespace-normalised
   - application link, after JobRec's canonical URL rule
   - description, after JobRec's HTML-to-text rule (Greenhouse, Ashby); non-empty for Lever, whose description is assembled from several fields
   - status is `open`
5. Command, from `app/`:

   ```
   PYTHONPATH=. python ../docs/verification/manual-tests/scripts/run_manual_tests.py tc027 <empty db path>
   ```

## Expected result

Every source is scraped without failure, and all 25 sampled listings match their live record on all five fields.

## Actual result

- Stored: 140 Figma, 299 Palantir, 170 Ramp listings (609 rows), no failed source.
- 25 of 25 sampled listings matched on all five fields (14 Palantir, 6 Figma, 5 Ramp).
